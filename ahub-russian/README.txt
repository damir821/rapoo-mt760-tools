Русский перевод Rapoo A HUB
===========================

A HUB читает тексты интерфейса из папки translations рядом с A HUB.exe.
Файл ru_RU.qm там пустой — этот перевод заполняет его (1657 строк).
Сама программа A HUB не изменяется.

Установка:
1. Запустите A HUB.
2. Дважды щёлкните «Установить перевод.cmd» — файл перевода встанет в папку
   A HUB, язык переключится на русский, A HUB перезапустится.

«Вернуть английский.cmd» возвращает всё как было (оригинальный файл
сохраняется в backup\ при установке).

После обновления A HUB перевод может слететь — просто установите его снова.

Файлы:
  dist\ru_RU.qm                    готовый перевод
  dist\ru_RU.translations.json     все строки: контекст, английский оригинал, русский
  tools\QmTool.cs                  чтение/сборка Qt .qm (dump / build / check)
  tools\ExtractQml.cs              достаёт QML из A HUB.exe и список qsTr-строк
  tools\Apply.ps1                  установка/откат
